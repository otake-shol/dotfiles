# A4 印刷物としての差分

配色・書体のトークンは create-story-slides の `references/design-system.md`（Standard）を正本とする。
ここにはスライドと違う点だけを書く。値は `assets/template.html` の CSS と一致させる。

## 用紙と余白

- A4 縦（210 × 297 mm）、`@page` の余白は 0 にして、本文の左右に 14 mm を取る
- ヘッダーは Primary Blue の帯を紙の端まで伸ばす（表紙の役割）
- フッターは常にページの下端に置く（内容が短くても途中で止めない）

## 文字サイズ（印刷して手に持って読む前提）

| 役割 | サイズ | 書体 |
|---|---|---|
| タイトル | 22 pt | Zen Maru Gothic・太字 |
| 見出し（h2） | 12 pt | Zen Maru Gothic・太字・Deep Navy |
| 項目名 | 10.5 pt | Zen Maru Gothic・太字 |
| 本文・説明 | 9.2〜9.8 pt（下限 9 pt） | Noto Sans JP |
| 注記・事務的な条件 | 8.8 pt 前後（下限 8.6 pt） | Noto Sans JP |
| 決定的な数字（料金） | 26 pt | Plus Jakarta Sans・太字（単位の「円」以外の和文は別の書体） |

- 説明文は Muted Ink（#65717E）の薄い灰色にしない。本文用の濃い色（#2B3640）を使う。Muted Ink は補足ラベル（日時・所要時間など）だけ
- 1 ページに収めるために下限より小さくしない。先に繰り返しと注記を削る

## 色の使いどころ

- Warm Canvas：紙の地
- Primary Blue：ヘッダー、流れの線、並列項目の縦線、決定的な数字
- Deep Navy：判断の到着点（料金）だけ。面で使うのは 1 か所まで
- 白い面＋Mist Gray の境界：成果物など、面で分ける必然がある 1 か所だけ
- Accent Orange：使わない（例外・介入の合図で、提案資料には通常ない）

## 番号

- 番号を付けるのは時間の順番（進め方）だけ。並列の項目には付けない
- 1 ページに番号の体系は 1 つ
