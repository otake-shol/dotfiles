# 視覚・音声資料の検証

## 検証対象の分離

素材の生成・加工の有無と、添えられた説明の正確性を分ける。本物の写真でも日時や場所が違えば誤解を招き、AI生成の図解でも内容を正しく説明できる。

## 画像

- 元投稿、過去の使用例、撮影時期と公開時期、付随する説明を調べる。逆画像検索が利用できれば完全一致・部分一致を探し、結果の掲載ページを開く。
- 検索サービスが最初に収集した日時を撮影日時や初公開日時と同一視しない。一致がない場合も新規撮影やAI生成の証明にはならない。
- 目視の違和感は追加調査の手がかりとする。圧縮、暗所、補正などでも不自然さが生じるため、指・影・文字の形だけで偽物と断定しない。

## 動画・音声

- 元の長尺版を探し、前後の発言、字幕・翻訳、日時、場所を照合する。切り抜きで条件や否定が落ちていないか確認する。
- 必要なら利用可能なローカルツールでキーフレームを抽出し、看板、ロゴ、建物、イベント名を検索の手がかりにする。確認した区間のタイムコードを残す。
- 音声と口の動きのずれや不自然な声だけでなりすましと断定しない。本人の公開発言や別経路の記録と照合する。
- 送金などの本人確認が問題になっている場合は既知の連絡先による確認を案内する。疑わしいメッセージ内の連絡先や、声が似ていることを本人確認の根拠にしない。

## 検知・来歴の限界

AI検知サービスやC2PA等の来歴表示を使う場合は対象形式、対応範囲、判定日時を記録する。偽陽性・偽陰性や再圧縮・再投稿による情報消失を考慮する。来歴が確認できても内容の真実性は保証されず、来歴がないことも偽物の証明にはならない。

逆画像検索や外部検知にはサービスへのデータ送信を伴う。非公開画像、顔写真、内部資料を無断でアップロードしない。人物の同一性を顔の見た目だけで推定せず、私人の特定や晒しにつながる調査をしない。ツールが使えない場合は実施可能な出典・文脈確認を行い、未検証部分を明示する。
